# llvm-dsdl User Manual

Compiler tooling for OpenCyphal DSDL, built on MLIR and LLVM.

The compiler is being rebuilt on the `reset/hourglass` branch. The frontend, the semantic analysis
and the build, test, packaging and documentation infrastructure are in the tree; the dialects, the
code generators and the tools follow, each to a golden its own ecosystem defines. `RESET.md` at the
repository root is the plan.
