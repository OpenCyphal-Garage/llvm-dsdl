# The lowering for a target writes the surface of its output last: the scopes the output opens and
# every name declared in them. Each language opens its own: C joins the namespace into each name and
# declares a type's constants as macros beside it, C++ opens a namespace, Go a package its files
# share, and Rust, TypeScript and Python a module per definition. A service's own name is an alias
# of its request, and a deprecated type is declared apart where the language does that. A scope the
# output writes to a file of its own names the file, and in Rust and Python a definition's module
# imports each definition its fields hold, and in TypeScript the functions named after it. A Rust or
# Python type holds the members the generator adds, each generated constant and data member naming
# the fact it states, and an accessors-only run declares no data member. A TypeScript or Python
# module declares the definition's facts at its top, and TypeScript's functions are the module's.
#
