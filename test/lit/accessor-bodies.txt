# A wire-flat section's fields sit at offsets the schema fixes, so `build-dsdl-plan-bodies` builds
# a getter and a setter for each scalar among them beside the three bodies. A getter is one read at
# the field's offset through the plan's own normalising helper, answering the value alone: a read
# cannot fail, and a short buffer zero-extends, so the answer is what `deserialize_` puts in the
# field. A setter is one write of the saturated value, answering the runtime's error code.
#
# A section that is not wire-flat gets none.
