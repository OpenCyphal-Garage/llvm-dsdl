# The pointer handed to a nested type is formed at the byte the cursor reached. A reader bounds
# that byte by the buffer's capacity: a read past the end zero-extends and still advances the
# cursor, and every backend can address the bounded byte. A writer's cursor cannot pass the
# capacity -- the check at the top of the plan established room for the whole layout -- so in a
# fixed layout the byte is a number and nothing bounds it.
#
