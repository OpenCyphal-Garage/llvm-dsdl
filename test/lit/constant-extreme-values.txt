# Regression: constant values across the full DSDL integer domain [INT64_MIN, UINT64_MAX] and
# integer-valued float constants must be representable and render as source that compiles in every
# backend. The constant/expression core was int64-bound, so uint64 values >= 2^63 and int64 == INT64_MIN
# were rejected at parse; and integer constants were rendered identically for all languages, so a
# `uint64` mask lost its unsigned suffix (Rust/C), a 64-bit constant was a plain `number` instead of a
# `bigint` (TypeScript), INT64_MIN was a bare negated literal that overflows i64 (Rust) / is unsigned
# (C), and a `float` constant equal to `2.0` was emitted as the integer `2` (a type error as f64 in
# Rust). See the emitter read-as-review / int64 constant range gap.

# RUN: rm -rf %t && mkdir -p %t/dsdl/kv
# RUN: printf 'uint64 MASK = 0xFFFFFFFFFFFFFFFF\nint64 FLOOR = -9223372036854775808\nuint64 SMALL = 5\nfloat64 HALF = 2.0\nuint8 d\n@sealed\n' > %t/dsdl/kv/K.1.0.dsdl
