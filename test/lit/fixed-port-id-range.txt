# A fixed port-ID wider than the field that carries it.
#
# `--allow-unregulated-fixed-port-id` widens which allocations may be used; it does not widen the
# field they are carried in. A subject-ID is thirteen bits and a service-ID is nine, so a value above
# those cannot be transmitted whatever the options say, and is rejected under both.
#
# Left accepted, it reaches the generated code: Rust declares the constant as `u16`, where a literal
# above 65535 does not compile at all, and C++ declares it as `std::uint16_t`, where it silently
# becomes a different port-ID.
