# `dsdl-build-wire-image-bodies` builds the bodies a target publishes over each section's serialise
# and deserialise that move a whole wire image, as the row's `wireImage` names them. Each calls its
# section's own entry point, offered the whole buffer. An encoder makes room for the section's
# largest image and keeps what the entry point used, or answers the bytes it was handed where the
# entry point fails. A reader that may keep none of its bytes reads an object holding a view from a
# copy of them. A row that publishes no wire image is built none.
