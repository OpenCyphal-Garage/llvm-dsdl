# A host-image type's generated structure is asserted to be the byte image its serialisation
# assumes, on the target the generated code is compiled for: its size, and each member's offset.
# The verdict was decided under natural alignment, and the assertions are where the target's
# compiler confirms it. A type that is not a host image gets none.
#
# Go carries the fold's endianness refusal as a build constraint in a file beside the type's, and
# its folded bodies view the object as bytes through `unsafe`.

# RUN: cat %t/c/fixtures_host_image/vendor/Padded_1_0.h | FileCheck %s --check-prefix=C_PADDED

# RUN: cat %t/cpp/pmr/fixtures_host_image/vendor/Nested_1_0.hpp | FileCheck %s --check-prefix=CPP_NESTED

# A host image allocates nothing, so under the PMR profile it carries no memory resource: the
# pointer would make the structure wider than the image, and inside a nested image it would move
# every field after it.
