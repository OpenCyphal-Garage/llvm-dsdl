# --prune-manifest: removing outputs a previous run of the same tranche produced.
#
# The defect this closes is quiet. Delete a definition and its generated header stays on the include
# path, so code that includes a type nobody defines any more keeps compiling -- and keeps compiling
# until somebody wipes the output directory by hand.
#
# Pruning is per invocation rather than per output directory because generation decomposes: a build
# may split one namespace across several dsdlc runs (support, the embedded catalog, definitions), and
# a run that swept --outdir would delete the files its siblings had just written.

# Set up a working copy, since this test deletes definitions.
# RUN: rm -rf %t.src && mkdir -p %t.src/ns
# RUN: cp %S/fixtures_prune/ns/Kept.1.0.dsdl %t.src/ns/
# RUN: cp %S/fixtures_prune/ns/Doomed.1.0.dsdl %t.src/ns/

# First run: nothing to prune, but the manifest is written.
# RUN: rm -rf %t.out %t.mf && %dsdlc --target-language c --outdir %t.out --prune-manifest %t.mf %t.src/ns >/dev/null 2>&1
# RUN: test -f %t.out/ns/Kept_1_0.h
# RUN: test -f %t.out/ns/Doomed_1_0.h
# RUN: test -f %t.mf

# A listing run must not prune: --list-outputs implies --dry-run, and a dry run that deleted files
# while reporting that it touched nothing would be the worst of both.
# RUN: rm %t.src/ns/Doomed.1.0.dsdl
# RUN: %dsdlc --target-language c --outdir %t.out --prune-manifest %t.mf --list-outputs %t.src/ns >/dev/null 2>&1
# RUN: test -f %t.out/ns/Doomed_1_0.h

# The real run removes the deleted definition's outputs and leaves the survivor alone.
# RUN: %dsdlc --target-language c --outdir %t.out --prune-manifest %t.mf %t.src/ns >/dev/null 2>&1
# RUN: not test -f %t.out/ns/Doomed_1_0.h
# RUN: not test -f %t.out/ns/Doomed_1_0.c
# RUN: test -f %t.out/ns/Kept_1_0.h

# Support code is not derived from a definition, so a types tranche must not take it with it.
# RUN: test -f %t.out/dsdl_runtime.h

# Tranche isolation: three runs sharing one output directory, each with its own manifest. Deleting a
# definition and re-running only the types tranche must leave the other two untouched -- this is the
# property that makes decomposed generation safe, and the one a per-directory sweep would break.
# RUN: rm -rf %t.multi %t.msrc %t.m1 %t.m2 %t.m3 && mkdir -p %t.msrc/ns
# RUN: cp %S/fixtures_prune/ns/Kept.1.0.dsdl %t.msrc/ns/

# RUN: not test -f %t.multi/ns/Doomed_1_0.h
