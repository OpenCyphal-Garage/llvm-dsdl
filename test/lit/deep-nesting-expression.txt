# Regression: a pathologically nested expression (tens of thousands of parentheses or set literals)
# must be rejected with a diagnostic, not overflow the recursive-descent expression parser's stack.
# Parenthesised sub-expressions and set literals re-enter Parser::parseExpression, which is now depth
# bounded (kMaxExpressionDepth); this crashed dsdlc and dsdld (shared frontend) before. See the
# recursion-depth / stack-overflow audit.

# RUN: not %dsdlc --target-language ast %t/x 2>&1 | FileCheck %s
# CHECK: expression nesting is too deep
