# Where a section's structure is a byte image of its wire form, its serialise and deserialise
# bodies fold into one move. The field-wise body is what every backend translates; the fold is an
# optimisation over it, applied only where the `host_image` verdict holds, and a body the fold
# does not recognise is left as it was.
#
# The checks assert the field work is gone, not only that a move appeared: a fold that adds the
# move beside the work it was meant to replace produces correct output at twice the cost, and a
# count of moves alone would pass it.

# A nested record's own deserialise call goes too: its error code is what a guard on the consumed
# count reads, and an image read cannot fail, so that code becomes zero rather than being kept. The
# zero decides the guard, and the count is stored unguarded.
# NEST_READ-LABEL: func.func @fixtures_host_image.vendor.Nested.1.0.deserialize(
# NEST_READ-NOT:   dsdl.call_serdes
# NEST_READ:       dsdl.image_read {{.*}} {bytes = 12 : i64}
# NEST_READ-NOT:   dsdl.call_serdes
# NEST_READ-NOT:   scf.if
# NEST_READ-NOT:   arith.cmpi eq
# NEST_READ:       dsdl.store_scalar
# NEST_READ:       return

# Two records, sixteen bytes: the second's deserialise runs under a guard on the first's code, and
# the code the body answers is that guard's. The guard is field work too, and goes with the calls.
