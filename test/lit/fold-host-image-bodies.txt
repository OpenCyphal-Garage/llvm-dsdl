# Where a section's structure is a byte image of its wire form, its serialise and deserialise
# bodies fold into one move. The field-wise body is what every backend translates; the fold is an
# optimisation over it, applied only where the `host_image` verdict holds, and a body the fold
# does not recognise is left as it was.
#
# The checks assert the field work is gone, not only that a move appeared: a fold that adds the
# move beside the work it was meant to replace produces correct output at twice the cost, and a
# count of moves alone would pass it.

# RUN: rm -rf %t && mkdir -p %t

# RUN: %dsdl-opt --pass-pipeline='builtin.module(lower-dsdl-bodies,dsdl-fold-host-image-bodies)' %t/plans.mlir > %t/folded.mlir
# RUN: FileCheck %s --check-prefix=FLAT_READ   < %t/folded.mlir
# RUN: FileCheck %s --check-prefix=FLAT_WRITE  < %t/folded.mlir
