# A generation run's naming manifest reports the whole surface its lowering wrote for its target:
# each definition's file, imports and guards and the helpers its file declares, and each section's
# declared type, entry points, the functions that wrap them, accessors, methods, the helpers its type
# declares, and the members and constants the generator adds, keyed by the fact each states. A
# service's own names are the definition's. C++ reports each profile's surface apart where the run
# writes several. Every name an analysis run reports, a generation run reports unchanged.
