# A module writes names of its own, and a type whose constant prefix is the module's own prefix can
# reach them: a constant of that name is escaped past the module's. Only the names the module
# actually writes are reserved -- a message's module writes no REQUEST_ or RESPONSE_ name, so a
# constant of that name collides with nothing and keeps its spelling.
