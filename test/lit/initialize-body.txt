# The third body a plan builds: the object at its defaults, as operations.
#
# Every step becomes a store of the type's zero -- a scalar, a length of nought, a tag of nought
# -- or a call into the nested type's own initialiser; there is no wire, so there is no cursor,
# no size, and no error but the null object. A union initialises every arm, not the one its tag
# selects: the value is observable only through the selected arm, and a type with no
# indeterminate storage is the one three backends already produce.
#
# A bool array is a run of bits in every target, bitpacked or one element per bool, and the one
# operation every target spells for that run is a bit read. Reading it from a buffer of no bytes
# is the spec's own definition of the default, implicit zero extension, applied to that array.
#
# The labels follow the module's order, which is the order the schemas were lowered in.
