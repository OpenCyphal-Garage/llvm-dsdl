# Regression: delimited (non-sealed) composite forward-compatibility skip in the C backend.
#
# On decode, a delimited composite is a 32-bit byte-length header followed by the nested object. The
# nested deserialize reports how many bytes it actually consumed, which may be FEWER than the header
# declares when a newer peer appended fields this reader does not understand. The outer offset MUST
# advance by the header-declared size, not by what the nested reader consumed -- otherwise every
# subsequent field is read from the wrong position (a decoded-buffer 04 00 00 00 01 02 AA BB 77 with a
# 2-field/2-byte reader would read `tail` as 0xAA instead of 0x77). The C/EmitC path reused one variable
# as both the nested inout-size (overwritten with consumed) and the advance amount; it now keeps the
# header size immutable and passes a separate consumed variable to the nested call. Rust/Go/C++/Python/TS
# already separated the two. See the wire-layout math read-as-review.
