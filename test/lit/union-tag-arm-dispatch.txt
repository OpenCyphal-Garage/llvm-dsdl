# A union's arms are selected by the value the plan validated and wrote, not by what came off
# the object. The tag is loaded, normalised through the serialise tag helper, and it is that
# result the validator sees, the wire receives and each arm's predicate compares against; the
# deserialise side does the same with the value read off the wire.
#
# The two are equal only because a tag's storage is never wider than its bit count, an
# invariant the analyser enforces. Selecting an arm on an unvalidated value would make the
# wire's tag and the arm that produced the payload disagree the moment that ceased to hold.
